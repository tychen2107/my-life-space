正在自動取得臺企銀匯率…
本金參考匯率依剩餘本金估算。估值採臺企銀「即期／本行買入」，不混用現鈔或小額匯率。若服務暫時失敗，系統會沿用上次成功報價。每日報價更新不會改動既有交易紀錄的成交匯率。

資料備份與還原

提醒：資料保存在目前瀏覽器本機。建議定期下載完整 JSON 備份；換手機、清除瀏覽器資料或更換瀏覽器前，請先備份。
備份檔名固定使用易辨識的英文格式 mylifespace_backup_YYYYMMDD.json，避免手機下載時中文檔名亂碼；首頁顯示標題仍預設為「亭有錢途」，可自行修改。

匯入備份會取代目前全部資料與個人化設定，請先確認已另行保存現有資料。舊版 JSON 也可以匯入。

完整 JSON 備份會包含外幣、基金、保險、旅遊資料，以及本機個人化設定。資料仍保存在各自瀏覽器，不會因分享同一網址而自動同步。本系統不會連線銀行帳戶或基金平台。
